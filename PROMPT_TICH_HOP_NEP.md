# Prompt bắt đầu dự án Companions

Hãy tạo web app companions trong thư mục này. Trước tiên khảo sát cấu trúc và asset hiện có; dùng Nếp trong `assets/` làm companion đầu tiên, giữ đúng kích thước/frame và animation chạy trái/phải riêng. Tổ chức code để sau này thêm Luna và nhân vật khác mà không trộn asset. Dùng công nghệ phù hợp với repository (nếu trống, chọn bộ công nghệ web gọn, phổ biến); không thêm dependency thừa. Làm giao diện responsive, hỗ trợ giảm chuyển động, rồi chạy kiểm tra phù hợp và báo cách khởi chạy cùng các file đã tạo.
